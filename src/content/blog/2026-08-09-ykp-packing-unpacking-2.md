# Unpacking Operator (언패킹 연산자)

사용 가능: `Python 3.5+`  
추가됨: [PEP 448](https://peps.python.org/pep-0448/)

리스트나 튜플 객체 앞에 `*`을 붙이면 그 객체를 언패킹 할 수 있습니다.

```py
print(*[1, 2, 3])
```

**출력 결과**

```
1 2 3
```

이것을 처음 보고 언패킹 연산자가 리스트를 띄어쓰기로 구분해준다고 생각 할 수 있습니다. 실제로는 아닙니다.

`*[1, 2, 3]`은 언패킹되어 다음과 같이 변합니다: `1, 2, 3`, 또한 `print`는 들어온 인자를 띄어쓰기로 구분하여 출력하므로 저런 결과가 나옵니다.

딕셔너리에서는 사용법이 조금 바뀝니다. 이렇게 쓸 수 있습니다.

```py
>>> {'x': 1, **{'y': 2}}
{'x': 1, 'y': 2}
```

또한 같은 key를 가진다면 이후에 추가된 값이 이전 값을 덮어씁니다.

```py
>>> {'x': 1, **{'x': 2}}
{'x': 2}

>>> {**{'x': 2}, 'x': 1}
{'x': 1}
```

또한 딕셔너리 언패킹은 함수에서 다음과 같이 해석됩니다.

```py
bar = {"a": 10, "b": 20}
foo(**bar)
```

```py
foo(a=10, b=20)
```

# 기타

`*args`, `**kwargs`는 잘 알려진 문법이므로 설명을 건너뛰겠습니다.
