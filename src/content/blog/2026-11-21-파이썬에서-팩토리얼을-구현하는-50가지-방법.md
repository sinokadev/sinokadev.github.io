사실 구현이라곤 했지만 첫번째 방법은 내장함수를 사용할 것이다.

## 목차

## 바퀴를 재발명하지 마세요

파이썬의 내장함수는 C언어로 구현되어서 for문을 사용하는것보다 효율이 좋다.

```py
import math

math.factorial(5)
```

간단하죠?

## 바퀴를 재발명해라

가끔은 <PostLink id="2026-02-05-바퀴를-재발명하지-말라">바퀴를 재발명하는것도 좋다</PostLink>. 파이썬에선 `for`를 사용할수 있다.

```py
def factori(n):
    result = 1
    for i in range(1,n+1):
        result *= i
    return result
```

물론 첫번째 방법이 더 낫다.

## 바퀴를 재발명하라 2

파이썬에는 반복문이 두가지가 있다. 첫번째는 `for`, 두번째는 `while`이다.

```py
def factori(n):
    result, i = 1, 1
    while i <= n:
        result *= i
        i += 1
    return result
```

물론... 저렇게 쓰지 말라고 `for`문이 있는거긴 하다.

## 제 귀요? 아뇨 재귀요.

재귀함수를 들어보았는가? 함수가 자기 자신을 실행해서 반복문과 비슷한 효과를 낸다.

```py
def factori(n):
    return n*factori(n-1) if n > 1 else 1
```

구현이 간단하다. 재귀는 꽤 맛있다고 생각한다. 간단한 짧은 코드로 전혀 이해되지 않는 동작이 나오기 때문이다. 물론 이해하기 어렵기 때문에 가독성은 최악이라 나는 별로 안 좋아한다.

## 동적 계획법

동적 계획법, 다이나믹 프로그래밍, DP를 써보자. 셋다 같은 말이다.

```py
def factori(n):
    dp = [1] * (n + 1)
    for i in range(2, n + 1):
        dp[i] = dp[i - 1] * i
    return dp[n]
```

DP의 장점은 재귀보다 빠르고 효율적이면서 같은 동작을 한다는 점이다. 다음으로 넘어가자.

## 캐시 (Cash말고 Cache)

동적 계획법이지만 한번 계산한걸 다시 게산하지 않으므로 전체 코드에서 팩토리얼을 여러번 사용한다면 꽤나 효율적이다.

```py
memo = {0: 1, 1: 1}

def factori(n):
    if n not in memo:
        memo[n] = n * factori(n - 1)
    return memo[n]
```

동적 계획법에 대해서는 나보다 다른 블로그가 더 잘 설명해준다. 나는 어제 동적 계획법을 (거의) 처음 배웠다.

## 타임 머신

`functools`라는 파이썬 내장 모듈에는 흑마법 함수들이 많이 들어있다. 그중 하나가 요즘엔 잘 안쓰이는 `reduce`이다.

```py
from functools import reduce

def factori(n):
    return reduce(lambda x, y: x * y, range(1, n + 1), 1)
```

귀도 반 로섬이 `reduce`를 가독성이 안 좋다고 `functools`로 내쫓았다. 불쌍한 리듀스... 사실 안 불쌍하다. 나는 아직도 저 코드를 이해하지 못했다.

## 파이썬은 스크립팅 언어이다

파이썬에는 개쩌는 내장 함수들이 많다.

```py
from functools import cache

@cache
def factori(n):
    return n * factori(n - 1) if n > 1 else 1
```

이것도 그중 하나다. 6번째로 다뤘던 구현 방법을 내장함수로 간단하게 구현했다. 파이썬은 스크립팅 언어이다. 내장 함수가 엄청나게 강력하다.

## 메타 프로그래밍

메타 프로그래밍에 대해 들어보았는가? 메타 프로그래밍은 소스코드를 수정하는 프로그래밍 기법이다. 다른 말로 흑마법이라고 부른다.

```py
def factori(n):
    if not n:
        return 1
    return eval('*'.join(map(str, range(1, n + 1))))
```

사실 이 방법은 아주 위험하다. 사실 정확히 어떻게 위험한지는 모르겠지만 eval은 위험하다고 들었다. 아, eval이 아니라 exec였나?

## exec

exec는 아주 위험하다.

```py
def factori(n):
    local_vars = {}
    code = f"""result = 1
for i in range(1, {n} + 1):
    result *= i"""
    exec(code, {}, local_vars)
    return local_vars['result']
```

이렇게 코드를 짤수 있을텐데, 이 경우에는 인젝션 공격에 취약해진다. 예시로 `n`에 `"print('Hello World') or 0"`를 넣으면 `Hello World`가 출력된다.

```py
factori("print('Hello World') or 0")
```

는 내부적으로

```py
result = 1
for i in range(1, print('Hello World') or 0 + 1):
    result *= i
```

이렇게 해석된다.

`print('Hello World')` 대신 다른 코드를 넣었다면, 그리고 그 코드가 해킹 코드라면 멸망이다. 

## 내장 함수

`math`에는 신기한 함수가 많다. 그중 `prod`를 써보겠다.

```py
import math

def factori(n):
    return math.prod(range(1, n + 1))
```

근데 `math`를 쓸거면 그냥 `math.factorial()`을 사용하면 되는거 아닐까?

## 리스트 컴프리헨션

리스트 컴프리헨션에 대해 알고있는가? 그럼 이 코드를 보라.

```py
def factori(n):
    res = 1
    return [res := res * i for i in range(1, n + 1)][-1] if n else 1
```

리스트 컴프리헨션은 분명 이렇게 쓰라고 만든 기능이 아니다.

## 수학

${}_n\mathrm{P}_n = n!$이다. 그러므로 이렇게 할수 있다.

```py
import math

def factori(n):
    return math.perm(n, n)
```

아까도 말했듯이, `math` 모듈을 사용할거면 그냥 `math.factorial()`을 써라.

## 순열

계속 말했지만, 파이썬에는 특이한 내장 함수가 많다.

```py
from itertools import permutations

def factori(n):
    return len(list(permutations(range(n))))
```

`permutations`가 도대체 뭐하는 함수인진 아직도 모르겠다. 이 코드는 $O(n \cdot n!)$이다. 그리고 쓸데없이 램을 아주 많이 사용한다.

## 감마 함수

감마 함수($\Gamma(n+1) = n!$)라는게 있다.

```py
import math

def factori(n):
    return round(math.gamma(n + 1))
```

나는 수학을 잘 못해서, 무슨 뜻이고 왜 작동하는지는 모른다.

## 곱셈 없이 팩토리얼

$\ln(n!) = \ln(1) + \ln(2) + \dots + \ln(n)$

```py
import math

def factori(n):
    return round(math.exp(sum(math.log(i) for i in range(1, n + 1))))
```

말했다시피, 나는 수학을 잘 모른다.

## try-except

`try-except`는 흑마법 입문할때 제일 먼저 배워야 할 기능이다.

```py
def factori(n):
    res = 1
    try:
        while True:
            1 / n
            res *= n
            n -= 1
    except ZeroDivisionError:
        return res
```

`n`이 0이 되면 0으로 나누기 에러가 나니, `while`에서 탈출할수 있다.

## 이게 하스켈인가요? 아니요. 파이썬입니다.

```py
factori = (lambda f: (lambda x: x(x))(lambda y: f(lambda v: y(y)(v))))(
    lambda f: lambda n: 1 if n == 0 else n * f(n - 1)
)
```

`lambda`는 최고의 난독화 기법이다.

## 자료형 창조

파이썬에서는 객체에 하는 연산을 함수로 하이재킹(?) 할수 있다.

```py
class Fact:
    def __init__(self, val=1):
        self.val = val
    def __mul__(self, other):
        return Fact(self.val * other)

def factori(n):
    f = Fact()
    for i in range(1, n + 1):
        f = f * i
    return f.val
```

커스텀 자료형을 만들 때 많이 사용되는 기능이다. 물론 팩토리얼은 굳이 이렇게 구할 필요가 없다.

## 리눅스 전용

리눅스에서만 작동되고 나머지 운영체제에선 작동되지 않는 코드가 있다면 어떨까?

```py
import subprocess

def factori(n):
    if n == 0:
        return 1
    cmd = f"seq -s '*' 1 {n} | bc"
    return int(subprocess.check_output(cmd, shell=True))
```

물론 `subprocess` 대신 `math`를 임포트 한다면 훨신 간단해질 것이다.

## 분할정복

나는 알고리즘을 잘 모른다. 

```py
def prod_range(low, high):
    if low > high:
        return 1
    if low == high:
        return low
    if high - low == 1:
        return low * high
    mid = (low + high) // 2
    return prod_range(low, mid) * prod_range(mid + 1, high)

def factori(n):
    return prod_range(1, n)
```

분할정복이 뭐하는 알고리즘인가? 말했듯이, 나는 잘 모른다. 이 코드는 `for`나 재귀에 비해 꽤 성능이 좋다고 한다. 

## Python Virtual Machine

파이썬은 인터프리터 언어가 아니다! CPython은 내부적으로 PVM 바이트코드로 컴파일된 후 실행된다.

그리고 PVM 바이트코드를 파이썬 코드 내에서 직접 사용하는 방법이 존재한다면 어떨까? 물론 존재한다.

```py
import dis
import opcode
import types


def _build():
    opmap = opcode.opmap
    caches = getattr(opcode, "_inline_cache_entries", {})

    def cache_count(name):
        if isinstance(caches, dict):
            return caches.get(name, 0)
        op = opmap[name]
        return caches[op] if op < len(caches) else 0

    mul_op = next(i for i, (_, sym) in enumerate(dis._nb_ops) if sym == "*=")
    sub_op = next(i for i, (_, sym) in enumerate(dis._nb_ops) if sym == "-=")

    instructions = []

    def emit(name, arg=0):
        idx = len(instructions)
        instructions.append((opmap[name], arg))
        for _ in range(cache_count(name)):
            instructions.append((opmap["CACHE"], 0))
        return idx, len(instructions)

    emit("RESUME", 0)
    emit("LOAD_CONST", 1)
    emit("STORE_FAST", 1)

    loop_start = len(instructions)
    emit("LOAD_FAST", 0)
    if "TO_BOOL" in opmap:
        emit("TO_BOOL", 0)

    jump_false_idx, after_jump_false = emit("POP_JUMP_IF_FALSE", 0)

    emit("LOAD_FAST", 1)
    emit("LOAD_FAST", 0)
    emit("BINARY_OP", mul_op)
    emit("STORE_FAST", 1)

    emit("LOAD_FAST", 0)
    emit("LOAD_CONST", 1)
    emit("BINARY_OP", sub_op)
    emit("STORE_FAST", 0)

    jump_back_idx, after_jump_back = emit("JUMP_BACKWARD", 0)
    instructions[jump_back_idx] = (
        opmap["JUMP_BACKWARD"],
        after_jump_back - loop_start,
    )

    exit_idx = len(instructions)
    instructions[jump_false_idx] = (
        opmap["POP_JUMP_IF_FALSE"],
        exit_idx - after_jump_false,
    )

    emit("LOAD_FAST", 1)
    emit("RETURN_VALUE", 0)

    bytecode = bytes(b for op, arg in instructions for b in (op, arg))

    code_obj = types.CodeType(1,0,0,2,2,3,bytecode,(None, 1),(),("n", "r"),"<bytecode>","factori","factori",1,b"",b"",)

    return types.FunctionType(code_obj, globals())

factori = _build()
```

이럴바엔 어셈블리를 쓰는게 낫지 않을까? 물론 그냥 `math` 모듈을 사용하면 된다.

참고로 저 코드는 Python 3.11에서 잘 작동한다고 한다.

## accumulate

`itertools`에는 누적 연산을 해주는 `accumulate`라는 라이브러리가 있다. 특이하게도 중간 과정을 모두 반환해준다

```py
import operator
from itertools import accumulate

def factori(n):
    return list(accumulate(range(1, n + 1), operator.mul, initial=1))[-1]
```

물론 우리는 마지막 값만 있으면 된다. 이럴거면 `sum`을 쓰라고? 그럴거면 이 글을 왜 읽는가? 당연히 `math.factorial()`가 낫다.

## deque

```py
from collections import deque
from itertools import islice

def _gen():
    i, res = 0, 1
    while True:
        yield res
        i += 1
        res *= i

def factori(n):
    return deque(islice(_gen(), n + 1), maxlen=1)[0]
```

나는 이게 어떻게 작동하는지 이해하기 귀찮아졌다.

## 이터레이터 자료형

파이썬에선 자료형을 창조할수 있다. 물론, 이터레이터 자료형도 창조할수 있다.

```py
class FactorialIter:
    def __init__(self, n):
        self.n = n
        self.curr = 0
        self.res = 1

    def __iter__(self):
        return self

    def __next__(self):
        if self.curr > self.n:
            raise StopIteration
        if self.curr > 0:
            self.res *= self.curr
        self.curr += 1
        return self.res

def factori(n):
    ans = 1
    for ans in FactorialIter(n):
        pass
    return ans
```

## 진지하게 좋음

지금까지 너무 개그만 한것같아서 진지한 수학 알고리즘을 들고왔다. 르장드로 공식과 에라토스테네스의 체를 섞은 방법이다.

```py
def factori(n):
    sieve = [True] * (n + 1)
    res = 1
    for p in range(2, n + 1):
        if sieve[p]:
            for m in range(p * p, n + 1, p):
                sieve[m] = False
            exp, k = 0, p
            while k <= n:
                exp += n // k
                k *= p
            res *= p ** exp
    return res
```

이건 정말 **진지하게 좋다**. 이건 $O(n \log \log n)$이다. $O(n)$인 for문보다 별로인게 아닌가 싶을수 있지만 **파이썬은 큰 수 곱셈이 느리다**. 이 코드는 곱셈 횟수를 줄여주므로 큰 수에서는 훨신 빠르다.

## 비트 시프트

나같이 로우 레벨을 좋아하는 사람은 알텐데, 컴퓨터는 곱셈보다 비트 시프트를 더 빠르게 처리할수 있다. 또한 비트 시프트는 2를 곱하는것과 같으므로 2를 곱하는 대신 사용할 수 있다.

```py
def factori(n):
    odd_prod = 1
    twos = 0
    for i in range(1, n + 1):
        x = i
        while x % 2 == 0:
            x //= 2
            twos += 1
        odd_prod *= x
    return odd_prod << twos
```

물론 현대의 컴퓨터는 곱셈 전용 회로가 들어있으므로 드라마틱한 차이는 없다. 그냥 `math.factorial()`를 쓰자.

## 너와 함께(with)라면

`with`문을 파일 열때만 써봤다면 당신은 파이썬 하수다. 물론 나도 파일 열때 말고 써본적 없다. 그러니 팩토리얼 할 때 사용해보도록 하자.

```py
class FactorialCtx:
    def __init__(self, n):
        self.n = n

    def __enter__(self):
        res = 1
        for i in range(1, self.n + 1):
            res *= i
        return res

    def __exit__(self, exc_type, exc_val, exc_tb):
        return False

def factori(n):
    with FactorialCtx(n) as res:
        return res
```

## 코루틴

```py
def _accumulator():
    res = 1
    while True:
        x = yield res
        res *= x

def factori(n):
    coro = _accumulator()
    ans = next(coro)
    for i in range(1, n + 1):
        ans = coro.send(i)
    return ans
```

## 비동기

```py
import asyncio

async def _async_fact(n):
    res = 1
    for i in range(1, n + 1):

    return res

def factori(n):
```

## 멀티프로세싱

CPU 코어가 여러개인데 고성능 팩토리얼 연산을 CPU 코어 하나한테 맡기는건 너무 가혹한 일이다. 코어 하나가 슬퍼하지 않도록 여러 코어에게 일을 분배해보자! 그러기 위해서 멀티프로세싱을 써보자.

```py
import math
from multiprocessing import Pool

def _mul_chunk(rng):
    return math.prod(rng)

def factori(n):
    mid = n // 2
    with Pool(2) as p:
        a, b = p.map(_mul_chunk, [range(1, mid + 1), range(mid + 1, n + 1)])
    return a * b
```

CPU야 행복하니?

## 메타클래스

파이썬 흑마법의 꽃, 메타클래스이다.

```py
class FactMeta(type):
    def __new__(cls, name, bases, dct):
        res = 1
        for i in range(1, dct["target"] + 1):
            res *= i
        dct["result"] = res
        return super().__new__(cls, name, bases, dct)

def factori(n):
    class Temp(metaclass=FactMeta):
        target = n
    return Temp.result
```

나는 아직도 메타클래스를 이해하지 못했다...

## 정규식씨가 누군가요?

정규식은 사람 이름이 아니다. 정규 표현식을 사용하여 곱셈을 할수 있다. 파이썬에서 정규 표현식을 쓰려면 `re` 모듈을 사용하면 된다.

```py
import re

def factori(n):
    s = "a"
    for i in range(1, n + 1):
        s = re.sub(r"a", "a" * i, s)
    return len(s)
```

...문자열 챕터와 다를게 없는 것 같다. 정규 표현식을 이딴데 쓰지 말자.

## AST (추상 구문 트리)

프로그래밍 언어를 개발해 본 사람이라면 AST에 대해 들어봤을 것이다. 파이썬은 AST를 직접 개발자가 제어할수 있도록 `ast`라는 모듈을 제공한다.

```py
import ast

def factori(n):
    expr = ast.Constant(value=1)
    for i in range(1, n + 1):
        expr = ast.BinOp(
            left=expr,
            op=ast.Mult(),
            right=ast.Constant(value=i),
        )
    tree = ast.fix_missing_locations(ast.Expression(body=expr))
    return eval(compile(tree, "<ast>", "eval"))
```

나는 `ast` 모듈을 쓰는 사람 한번도 본적 없다.

## 분수

사람은 자기 분수에 맞게 행동해야 한다. 뭔 소리냐고? 나도 모른다. 분수를 사용해보자.

파이썬에는 분수를 다루는 `fractions`라는 내장 모듈이 있다. 

```py
from fractions import Fraction

def factori(n):
    res = Fraction(1, 1)
    for i in range(1, n + 1):
        res /= Fraction(1, i)
    return res.numerator
```

## 유한차분법

$$
n! = \sum_{k=0}^{n} (-1)^{n-k} \binom{n}{k} k^n
$$

이게 뭐하는 공식인지 아는 사람이 있을까? 나는 수학을 잘 모른다.

```py
import math

def factori(n):
    return sum((-1) ** (n - k) * math.comb(n, k) * (k ** n) for k in range(n + 1))
```

아무튼, 저 공식을 사용하면 팩토리얼을 구할 수 있다.

## [클로저 마트료시카](https://en.wikipedia.org/wiki/Closure_(computer_programming))

```py
def factori(n):
    f = lambda: 1
    for i in range(1, n + 1):
        f = (lambda func, k: lambda: func() * k)(f, i)
    return f()
```

이젠 난 모르겠다. 알아서 생각해라.

## 우선순위 큐

최소 힙으로 팩토리얼을 구할수 있다.

```py
import heapq

def factori(n):
    if n <= 1:
        return 1
    h = list(range(1, n + 1))
    heapq.heapify(h)
    while len(h) > 1:
        heapq.heappush(h, heapq.heappop(h) * heapq.heappop(h))
    return h[0]
```

말했다시피, 나는 알고리즘을 잘 모른다. 최소 힙이 뭔지 모른다.

## 스레딩

비동기, 멀티프로세싱 그 다음은? 맞다. 스레딩이다.

```py
import threading

def factori(n):
    res = [1]

    def worker(i, prev):
        if prev:
            prev.join()
        res[0] *= i

    prev = None
    for i in range(1, n + 1):
        t = threading.Thread(target=worker, args=(i, prev))
        t.start()
        prev = t
    if prev:
        prev.join()
    return res[0]
```

굳이 이렇게 할 필요 없다.

## 선형대수학

나는 그래픽스를 배우고 있다. 그래픽스에는 선형대수학이 쓰이는 지라 꽤나 아늑한 개념이다.

```py
import numpy as np

def factori(n):
    if n == 0:
        return 1
    return round(np.linalg.det(np.diag(range(1, n + 1))))
```

## 매치 케이스

`switch-case`문을 아는가? 파이썬은 이게 없었다. 다른 언어들이 부러웠던 파이썬은 결국 Python 3.10에 들어서야 `match-case`라는 기능을 추가했다.

```py
def factori(n):
    match n:
        case 0 | 1:
            return 1
        case _:
            return n * factori(n - 1)
```

굳이 왜 `switch`라는 익숙한 이름을 안 쓴건진 모르겠다. 지네들 말로는 스위치 케이스보다 더 낫다고 하는데, 난 잘 모르겠다.
