# 패킹(Packing)과 언패킹(Unpacking)

## 패킹

사용 가능: `Python 1.0+`

파이썬의 `print` 함수를 사용할 때 인자로 들어온 여러개의 객체들을 한꺼번에 출력할 수 있습니다. 입력된 인자들은 띄워쓰기로 구분되어 출력됩니다.

```py
a = 10
print("a:", a)
```

**출력 결과**

```
a: 10
```

입력 인자의 갯수에는 제한이 없으며, 이러한 것을 패킹 또는 가변 인자라 부릅니다.

또한 패킹은 변수를 선언할 때도 사용 가능합니다.

```py
a = 1, 2, 3
print("a:", a)
print("a type:", type(a))
```

**출력 결과(Python 3.10)**

```
a: (1, 2, 3)
a type: <class 'tuple'>
```

괄호를 생략해도 객체들을 튜플로 묶어 저장해 주는 모습을 볼 수 있습니다.

## 언패킹

사용 가능: `Python 1.0+`

언패킹은 튜플이나 리스트를 여러개의 변수에 나눠 담을 수 있게 해주는 문법입니다.

```py
a, b, c = (1, 2, 3)
print(a, b, c)
```

**출력 결과**

```
1 2 3
```

언패킹하려는 각각의 변수를 리스트처럼 쓸 수도 있습니다.

```py
[a, b, c] = (1, 2, 3)
```

실제로는 같은 작업을 수행합니다.

또한 패킹과 언패킹을 동시에 쓸 수도 있습니다.

```py
a, b, c = 1, 2, 3
```

이런걸 다중 할당(Multiple Assignment)이라 부릅니다.

또한 언패킹은 리스트에서 쓸 수도 있습니다.

```py
for a, b in [(1, 2), (3, 4)]:
    print(a, b)
```

**출력 결과**

```
1 2
3 4
```

# Extended Iterable Unpacking (확장된 언패킹)

추가됨: [PEP 3132](https://peps.python.org/pep-3132/)  
사용 가능: `Python 3.0+`

이 기능은 언패킹을 더 유용하게 사용할 수 있게 도와주는 기능입니다. 예시를 봅시다.

이전 버전에서는 이렇게 했어야 합니다:

```py
a = (1, 2, 3, 4, 5)

first, middle, last = a[0], list(a[1:-1]), a[-1]

print(first, middle, last)
```

**출력 결과(Python 3.10)**

```
1 [2, 3, 4] 5
```

하지만 이 기능을 사용하면 더 효율적으로 같은 작업을 수행할 수 있습니다.

```py
first, *middle, last = (1, 2, 3, 4, 5)
print(first, middle, last)
```

**출력 결과(Python 3.10)**

```
1 [2, 3, 4] 5
```

이렇게 확장된 언패킹을 활용하면 이전 버전에서 보다 더욱 깨끗하고 효율적인 방법으로 데이터를 나눌 수 있습니다.

또한 특이한 점으로는 이 코드는 유효하지 않습니다.

```py
*a = range(5)
```

하지만 이 코드는 유효합니다.

```py
*a, = range(5)
```

또한 `for`문에서의 언패킹과 섞어서 이렇게 쓸 수도 있습니다.

```py
for a, *b in [(1, 2, 3), (4, 5, 6, 7)]:
    print(b)
```

**출력 결과**

```
[2, 3]
[5, 6, 7]
```
